# MOONREST — asset provenance

Every asset in this directory is **generated by this repository's own tools**
from code committed here. Nothing is downloaded, purchased, scraped, or derived
from a third-party pack, so there is no third-party licence to honour: the
assets carry the same licence as the repository.

The generator is committed alongside the output on purpose — the `.glb` files
are build products, and `tools/` is the source they were built from. Anything
here can be regenerated with `npm run assets`.

| Asset | Generator | Notes |
|---|---|---|
| `models/trees/tree_00..03.glb` | `tools/make_tree.py` | Hero park trees. Procedural trunk spine + forking limbs + faceted canopy masses, bark displace, bevel, decimate. ~4.4–5.3k tris each (budget 2k–20k, DIRECTION/ASSETS Part 1). Seeded, so the family is reproducible. |

**Blender is a dev dependency, never a runtime one** (FINAL_PASS Part 5). The
shipped game loads GLB; it does not need Blender installed.
